CBCentra School Management System

Privacy Policy

Last updated: 26 October 2026

CBCentra School Management System ("CBCentra") is a desktop application developed and maintained by Ben Ewoku, Kampala, Uganda. This policy explains what Google user data CBCentra accesses when a school connects a Gmail account, why it does so, and how that data is stored and protected.

CBCentra runs on the school's own computers and local network. Ben Ewoku does not operate a server that receives, stores or processes your Gmail data.

What CBCentra is

CBCentra is installed on computers at the school. One designated computer, the email server machine, connects a single Gmail account that the school chooses. Other computers on the school network then use that connection through the school's own database. The Gmail account is normally the school's official mailbox.

Google user data we access

When an authorised administrator signs in to Google from CBCentra, the app requests these permissions:

  • gmail.send: to send emails (for example fee notices, announcements and report notifications) from the school's address.
  • gmail.readonly: to read messages in the connected mailbox so that incoming mail and replies can be shown inside CBCentra.
  • gmail.modify: to update message state, such as marking messages as read, so the in-app inbox matches the mailbox.

CBCentra also reads the email address of the connected account, so that it can display which mailbox is signed in.

How we use this data

We use Google user data only to provide the email features the school sees inside CBCentra: sending messages, showing conversations and attachments, and keeping read status in step with Gmail. We do not use it for advertising, profiling, or any purpose unrelated to those features.

CBCentra's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Where the data is stored

  • Authorisation token. After sign-in, Google issues a token that lets CBCentra act on the mailbox. It is stored in the school's own MySQL database, and a backup copy may be kept in the application's local files on the server machine. It is never sent to Ben Ewoku.
  • Email content. Messages, conversation details and attachments that CBCentra displays or sends are stored in the school's own database and file storage on its local network.

The school controls that database and the computers it runs on, and is responsible for securing them, for example with access controls, regular backups and user accounts for staff.

Sharing and disclosure

We do not sell Google user data. We do not share it with third parties, transfer it to other companies, or use it to train artificial intelligence or machine learning models. The only parties who can see the data are the school's own authorised CBCentra users. Data may be disclosed if the school is required to do so by law.

Human access

The developer does not read a school's emails. If the school asks for technical support, access to data happens only with the school's permission and only as far as needed to fix the problem.

Retention and deletion

The school decides how long emails and tokens are kept, because they live in the school's own systems. An administrator can disconnect Gmail at any time with the Revoke button in CBCentra's email settings. This removes the stored token from the database and from the local files on the server machine. Messages already stored in CBCentra's database stay there until the school deletes them.

You can also withdraw access directly from Google at any time at myaccount.google.com/permissions.

Security

Access to Gmail is limited to the single server machine that completed sign-in. Other computers cannot start the Google sign-in flow and only use the stored authorisation. Communication with Google's servers uses HTTPS.

Changes to this policy

If CBCentra's handling of Google user data changes, we will update this page and its date. Changes that affect how Google data is used will be reflected here before they take effect.
