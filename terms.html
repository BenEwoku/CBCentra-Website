3. Permissions and how they are used

CBCentra requests the following Google permissions:

  • gmail.send: to send emails from the school's address.
  • gmail.readonly: to read messages in the connected mailbox so they can be shown inside CBCentra.
  • gmail.modify: to update message state, such as marking messages as read.

CBCentra uses these permissions only to provide the email features the school sees inside the application. It does not use them for advertising, profiling or any unrelated purpose.
